# WhatsApp Web

Controls use visible labels.

## Open a chat
1. The search box is "Search or start a new chat". TYPE_TEXT the group or contact name.
2. Click the matching chat in the results list (its label contains the name and a
   preview). Opening it satisfies "search for the group".

## Send a message
1. After the chat is open, the message box is "Type a message".
2. TYPE_TEXT the message, then click the Send button.

## Mentions (important)
A mention is NOT plain text. Typing "@Name" as text does not create a mention.
To mention a member:
1. TYPE_TEXT "@" alone in the message box.
2. WAIT for the member popup list to appear.
3. CLICK the member's name in the popup. This inserts a real highlighted mention.
4. Repeat steps 1-3 for every member you need to mention.
5. Only after all mentions are inserted, TYPE_TEXT the rest of the message if
   needed, then click Send.

Do not type member names manually. If the popup does not appear, the mention was
not created; try again with "@".
